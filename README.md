Lista de Exercícios (HTML + CSS + JavaScript) 

------------------------------------------------------------------------------------

Os exercícios devem ser responsivo, bem estruturado, usando HTML, CSS e JavaScript, aplicando estrutura de decisão, comandos de repetição e funções. 

 

Requisitos obrigatórios de JavaScript  

----------------------------------------------------------------------------------

1) Estrutura de decisão (if / else ou switch) 

2) Comando de repetição (for / while ) 

3) Funções (function ) 


-----------------------------------------------------------------------------------------
 

Requisitos de layout (CSS) 

Layout organizado e agradável (cores, espaçamento, alinhamento) 
Tipografia legível 
Menu de navegação para as seções (fixo ou no topo) 
Site responsivo (funcionar no celular e no computador) 
Entrega 

Você deverá entregar uma pasta com: 

index.html 
style.css 
script.js 
Pasta /img (se usar imagens)
